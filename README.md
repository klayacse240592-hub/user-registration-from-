# User Registration Form

This project is a simple User Registration Form created using HTML, CSS, and JavaScript.

## Files

- `index.html` - Contains the registration form.
- `style.css` - Provides styling for the form.
- `script.js` - Handles form validation and functionality.
- `sucess.html` - Displays the successful registration page.

## Features

- User registration form
- Form validation
- Responsive design
- Success page after registration

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Fill in the registration form.
4. Submit the form to see the success page.
